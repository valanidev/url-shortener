# URL Shortener

Raccourcisseur d'URL rapide avec suivi analytique en temps réel.

## Démo & Stack

- **Stack :** Next.js, TypeScript, Tailwind CSS, Prisma, PostgreSQL
- **Démo :** soon

## Fonctionnalités

- Création de liens courts
- Liens temporaires (expiration à 7 jours sans compte)
- Redirection rapide
- Analytics : nombre de clics, pays, OS et navigateurs
- Respect de la vie privée (anonymisation des adresses IP)

## Installation

1. **Cloner le projet :**
   ```bash
   git clone [https://github.com/valanidev/url-shortener.git](https://github.com/valanidev/url-shortener.git)
   cd url-shortener
   ```
